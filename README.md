# FitZone Gym – Static Demo Website

A responsive, single-page website for a fictional gym in Vashi, Navi Mumbai. Built as a static front-end demo with sample content.

**Live demo:** [ https://YOUR-GYM-SITE.vercel.app](https://gym-lemon-six.vercel.app/)

## Features

- Responsive dark-theme design for mobile, tablet and desktop
- Sections: Home, About, Services, Membership Plans, Trainers, Gallery, Opening Hours and Class Schedule, Testimonials, Free Trial, Location, FAQ, Contact
- Free trial booking form, contact form and review form with validation
- Demo mode: forms do not send data and show a "demo submitted" message instead
- Google Maps embed and WhatsApp chat button
- Accessible markup (ARIA labels, semantic HTML, alt text)

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)
- Bootstrap 5
- Bootstrap Icons

## Project Structure

```
├── css/          Custom styles
├── images/       Site images
├── js/           site.js and demo-forms.js
├── storage/      Trainer and gallery photos
├── vendor/       Bootstrap and Bootstrap Icons
├── favicon.ico
└── index.html
```

## Run Locally

```bash
git clone https://github.com/anuja2793/gym-management.git
cd gym-management
```

Open `index.html` in your browser, or use a local server such as the VS Code Live Server extension.

## Note

This is a demo project. All names, prices, phone numbers, emails and addresses are fictional sample data.
